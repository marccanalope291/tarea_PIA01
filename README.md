# tarea_PIA01 - Hola Mundo

## Descripción
Este repositorio forma parte de una actividad de introducción a GitHub y al control de versiones.
El objetivo es crear un primer proyecto que incluya un programa sencillo en Python que muestre el mensaje **¡Hola Mundo!** por pantalla.

## Contenido del repositorio
- `README.md`: documentación básica del proyecto.
- `hola_mundo.py`: programa escrito en Python.

## Objetivo
Familiarizarse con la creación de repositorios, la gestión de archivos y el uso básico de GitHub.
